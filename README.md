# 汉字卡片 · 한자 플래시카드

HSK 1~2급 한자를 카드 형태로 학습하는 단일 HTML 파일 웹앱입니다. 경기대학교 중어중문전공 학습용 개인 프로젝트입니다.

## 사용 방법

`index.html` 파일을 브라우저로 열기만 하면 됩니다. 별도 설치나 빌드 과정이 없습니다.

```
git clone https://github.com/aseo13yeon-kgu/hanzi-card.git
cd hanzi-card
# index.html을 브라우저로 열기
```

## 기능

- 카드 뒤집기(앞: 한자, 뒤: 병음 + 한국어 뜻)
- 이전/다음 카드 이동, 순서 섞기/초기화
- 급수 선택(HSK 1급 / 2급)
- 알아요 / 몰라요 체크로 암기 여부 표시
- 모르는 단어만 다시 보는 복습 모드
- 즐겨찾기(⭐)로 어려운 단어 표시
- 진행률(아는 단어 수 / 전체, %) 표시
- 학습 상태는 브라우저 `localStorage`에 저장되어 새로고침 후에도 유지

## 키보드 단축키

| 키 | 동작 |
|---|---|
| ← / → | 이전 / 다음 카드 |
| Space | 카드 뒤집기 |
| K | 알아요로 표시 |
| D | 몰라요로 표시 |
| F | 즐겨찾기 토글 |

## 기술 스택

순수 HTML / CSS / Vanilla JavaScript. 외부 라이브러리 없이 Google Fonts(`Noto Serif SC`, `Noto Sans KR`)만 사용합니다.
